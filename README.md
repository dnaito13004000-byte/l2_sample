# L2点群サンプル

ルックアップドローンが DJI Matrice 400 ＋ Zenmuse L2 で計測した山林の点群（100万点）を、ブラウザで見られるサンプルです。スマホにも対応しています。

## できること
- 3D表示（RGB・標高・反射強度・分類・地上高で色分け）
- 木を消して地表面だけを表示
- 断面図（スライダーで断面線を移動、東西／南北の切り替え、縦倍率表示）
- 断面上での2点計測（水平距離・高低差・斜距離・勾配）
- 樹木の自動カウント（樹高・樹冠径の一覧をExcel用にコピー）
- 自分のLASファイルを開いて同じ解析（複数ファイルの結合にも対応）

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | ビューワー本体（1ファイル完結。three.js は CDN から読み込み） |
| `cloud.txt` | サンプル点群。独自形式（LUPC）を base64 にしたもの |

## 手元で開く
`cloud.txt` を読み込むため、ファイルを直接ダブルクリックではなく、簡易サーバー経由で開きます。

```
python -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## サンプルデータについて
- 元データ（約2,500万点）から、表示用に約4%の100万点を間引いています。座標は現場中心を原点とした値で、緯度経度は含みません。
- 標高はジオイド高を約33mと仮定した概算値です。成果品としての精度はありません。
